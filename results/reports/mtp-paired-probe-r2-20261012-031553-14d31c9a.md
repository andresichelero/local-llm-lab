- **Token streaming rate vs. native decode:** The reported output tokens per second is effective streaming rate computed as `completion_tokens / (wall_time_s - TTFT)`, which includes the first token while excluding its latency from the denominator. This differs from native server decode speed; both streaming rate, native decode and total end-to-end wall time must be reported without conflation.
- **No agentic coding claim:** These small-sample timing observations reflect a diagnostic activation probe and do not validate agentic programming gains or operational efficiency.
