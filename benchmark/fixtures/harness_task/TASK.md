# Reproducible coding-agent task

In `src/calculator.py`, implement `divide(a, b)` using normal numeric division. If `b` is zero, raise `ValueError` with the message `division by zero`. Add focused unit tests named test_divide_positive, test_divide_negative, and test_divide_by_zero (or equivalent clear test methods). Run `python3 -m unittest discover -s tests -v` from the workspace root and leave `add` and `multiply` unchanged. Do not add dependencies or use pytest.

Success is graded by the checked-in tests, a separate behavioral probe, and the changed-file list. The task contains no network, credentials, or external dependencies.
